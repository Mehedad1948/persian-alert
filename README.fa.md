# Persian Alert (هشدار تایپ فارسی)

[English](README.md) | **فارسی**

یک برنامه‌ی کوچک ویندوزی که کنار ساعت ویندوز (در سینی سیستم) اجرا می‌شود و **وقتی شروع به تایپ فارسی می‌کنید یک بوق کوتاه می‌زند**؛ تا قبل از اینکه یک جمله‌ی کامل را با زبان اشتباه بنویسید متوجه شوید.

- فقط **یک بار** در شروع تایپ فارسی بوق می‌زند و بعد ساکت می‌ماند، تا وقتی که به انگلیسی تایپ کنید یا به پنجره‌ی دیگری بروید.
- در برنامه‌هایی که فارسی نوشتن در آن‌ها عادی است بوق نمی‌زند (به‌طور پیش‌فرض تلگرام؛ قابل تغییر است).
- با **Ctrl+Alt+P** یا یک کلیک روی آیکون برنامه روشن یا خاموش می‌شود.

فقط برای ویندوز.

## حریم خصوصی

برنامه فقط هر حرفی را که تایپ می‌کنید در حافظه بررسی می‌کند تا ببیند فارسی است یا نه. متن تایپ‌شده‌ی شما **هیچ‌وقت ذخیره، ثبت یا به جایی ارسال نمی‌شود** و برنامه هیچ کدی برای اتصال به اینترنت ندارد. کل برنامه یک فایل خوانا است: [`src/PersianAlert.ahk`](src/PersianAlert.ahk).

## نصب

1. فایل `PersianAlert.exe` را از [آخرین نسخه](https://github.com/Mehedad1948/persian-alert/releases/latest) دانلود کنید.
2. آن را در یک پوشه‌ی ثابت بگذارید، مثلاً `C:\Users\<you>\Apps\PersianAlert\`. فایل تنظیمات `settings.ini` کنار آن ساخته می‌شود.
3. روی آن دوبار کلیک کنید. یک اعلان نشان می‌دهد که برنامه اجرا شده است. آیکون برنامه کنار ساعت ویندوز است (اگر آن را نمی‌بینید، روی فلش **^** کنار ساعت کلیک کنید).
4. برای اجرای خودکار هنگام روشن شدن ویندوز: روی آیکون راست‌کلیک کنید ← **Start with Windows**.

### هشدار ویندوز یا آنتی‌ویروس

فایل exe امضای دیجیتال ندارد و برای تشخیص تایپ فارسی، کلیدهای فشرده‌شده را زیر نظر می‌گیرد؛ به همین دلیل ممکن است ویندوز یا آنتی‌ویروس هشدار بدهد:

- **SmartScreen** (پیام «Windows protected your PC»): روی **More info** و بعد **Run anyway** کلیک کنید.
- **آنتی‌ویروس**: این یک هشدار اشتباهِ شناخته‌شده برای برنامه‌هایی است که با AutoHotkey ساخته شده‌اند. اگر نمی‌خواهید به فایل exe اجازه بدهید، می‌توانید برنامه را [از روی سورس اجرا کنید](#اجرا-از-روی-سورس).

برای اطمینان از اینکه فایل دانلودشده دقیقاً همان فایلی است که GitHub Actions از کد همین مخزن ساخته، هش آن را با فایل `PersianAlert.exe.sha256` همان نسخه مقایسه کنید:

</div>

```powershell
Get-FileHash .\PersianAlert.exe -Algorithm SHA256
```

## استفاده

| کار | روش |
|---|---|
| روشن یا خاموش کردن | **Ctrl+Alt+P** یا کلیک روی آیکون. وقتی خاموش است، آیکون حرف **S** را نشان می‌دهد. |
| تغییر تنظیمات | راست‌کلیک روی آیکون ← **Edit settings**، فایل را ذخیره کنید، سپس **Reload settings** |
| اجرا هنگام روشن شدن ویندوز | راست‌کلیک روی آیکون ← **Start with Windows** |
| بستن برنامه | راست‌کلیک روی آیکون ← **Exit** |

## تنظیمات

فایل `settings.ini` کنار برنامه قرار دارد:

</div>

```ini
[General]
ToggleHotkey=^!p

[Beep]
Frequency=1500
DurationMs=150

[Apps]
Ignore=Telegram.exe
Only=
```

<div dir="rtl">

| تنظیم | توضیح |
|---|---|
| `ToggleHotkey` | میان‌بر روشن/خاموش کردن. `^` یعنی Ctrl، `!` یعنی Alt، `+` یعنی Shift و `#` یعنی Win |
| `Frequency` | زیر و بمی صدای بوق به هرتز (۳۷ تا ۳۲۷۶۷) |
| `DurationMs` | مدت بوق به میلی‌ثانیه (۱ تا ۲۰۰۰) |
| `Ignore` | برنامه‌هایی که هرگز در آن‌ها بوق نمی‌زند (با کاما جدا کنید) |
| `Only` | اگر پر شود، فقط در همین برنامه‌ها بوق می‌زند |

نام برنامه‌ها را در **Task Manager ← Details ← Name** پیدا کنید (مثلاً `chrome.exe`، `Code.exe` یا `WhatsApp.exe`).

توضیحات را در یک خط جداگانه بنویسید که با `;` شروع شود؛ توضیحی که بعد از یک مقدار در همان خط بیاید، جزو همان مقدار حساب می‌شود.

## حذف برنامه

راست‌کلیک روی آیکون ← تیک **Start with Windows** را بردارید ← **Exit**. سپس پوشه‌ی برنامه را پاک کنید.

## اجرا از روی سورس

1. AutoHotkey v2 را نصب کنید: `winget install AutoHotkey.AutoHotkey`
2. روی فایل `src/PersianAlert.ahk` دوبار کلیک کنید.

## ساخت فایل exe

</div>

```powershell
./build.ps1
```

<div dir="rtl">

این اسکریپت نسخه‌های مشخص و ثابتی از AutoHotkey و کامپایلر آن (Ahk2Exe) را در پوشه‌ی `.tools/` دانلود می‌کند، هش SHA-256 آن‌ها را بررسی می‌کند و فایل `dist/PersianAlert.exe` را همراه با فایل `.sha256` آن می‌سازد.

## انتشار نسخه‌ی جدید

1. شماره‌ی نسخه را در هر دو جای `APP_VERSION` و `;@Ahk2Exe-SetVersion` در فایل `src/PersianAlert.ahk` به‌روز کنید.
2. تغییرات را commit کنید، سپس تگ بزنید و push کنید:

</div>

```powershell
git tag v1.0.1
git push origin main v1.0.1
```

<div dir="rtl">

3. GitHub Actions فایل exe را از روی کد همان تگ می‌سازد و آن را همراه با فایل SHA-256 منتشر می‌کند.
